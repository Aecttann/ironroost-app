Ironroost: レトロ戦車バトル

## Short description (max 80)

## Full description (max 4000)
敵の戦車がマップの上から押し寄せる。あなたの基地は下、数列のレンガの向こう。守り抜け。

Ironroostは、1980年代の家庭用ゲーム機の雰囲気を持つオリジナルのアーケード戦車ゲームです。小さなフィールド、撃ち崩せる壁、そして同じものを狙って次々と現れる敵。

35の手作りステージ
すべてのマップはこのゲームのために作られています。レンガを4分の1ずつ撃ち抜き、森に隠れ、氷の上を滑り、水や鋼鉄を回り込む道を見つけよう。ステージは順番に解放され、進むほど難しくなります。

敵を知れ
ノーマル、ファスト、パワー、アーマーの戦車はそれぞれ戦い方が違います。点滅する戦車を倒すとボーナスが出現します:
• スター – 段階的に強くなる主砲。最後は鋼鉄も撃ち抜ける
• 砲弾 – 一気に最大火力
• シールド – 数秒間の防御
• 砂時計 – すべての敵が停止
• 鋼板 – 基地の壁がしばらく鋼鉄に
• 爆弾 – フィールド上の敵を一掃
• ハート – 残機が1つ増える
• ボート – 水の上を進める

エンドレスモード
ひとつのアリーナで、どんどん厳しくなるウェーブ。ウェーブをクリアするたびに3つのアップグレードから1つを選べます:連射、二連射、装甲、跳弾、スピードを上げる履帯、徹甲弾、毎ウェーブ基地の壁を鋼鉄にする防壁、残機を1つ増やす補給。毎回ちがう戦車ができあがります。どこまで行けるか?

明日もまた来よう
デイリー報酬を受け取って、次のプレイにボーナス残機を。7日連続で受け取るとコレクションカードがもらえます。「保護」があれば、1日逃しても連続記録は途切れません。

コレクションと記録
撃破数、ボーナス、キャンペーンの節目、特別な達成でもらえる20枚のコレクションカード。キャンペーンとエンドレスそれぞれの自己ベストトップ10は端末に保存されます。
